UX Basics
UX means user experience: how easy and pleasant something is to use. Good UX means people get what they came for without getting stuck.

The 6 basics
Know the user's goal: every page should help someone do one main thing. Figure out what that is first.
Keep it simple: fewer choices, fewer steps. If it can be removed without hurting anything, remove it.
Be consistent: same things should look and work the same way everywhere. People shouldn't have to relearn.
Give feedback: when someone clicks, show that something happened. A button changes color, a "Saved!" message appears.
Make things easy to find: clear menus and labels. People should never wonder "where do I go?"
Design for everyone (accessibility): readable text, strong contrast, buttons big enough to tap, and it works for people using screen readers.
Quick check
Before calling a design done:

Is the main goal of the page obvious?
Could a first-time visitor figure it out without help?
Does every click give some kind of response?
Is it readable and tappable for everyone?
Best test of all: watch a real person try to use it, and don't help them.
